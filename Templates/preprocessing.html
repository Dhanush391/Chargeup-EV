Data Preprocessing & Feature Engineering

Transformation pipeline converting raw session logs into chronological, leakage-free hourly forecasting features.

82,606 Hourly Steps Created

5-Stage Data Pipeline Architecture

STAGE 1 Charging Sessions 259k+ raw session logs
STAGE 2 Data Cleaning Drop invalid timestamps, nulls, energy ≤ 0
STAGE 3 Datetime Conversion Mixed format ISO datetime parsing
STAGE 4 Hourly Aggregation Sum energy per continuous hour
STAGE 5 Feature Engineering Lags (t-1, t-24), hour, day, weekend

Engineered Feature Set (Zero Leakage)

Feature Name Description Range / Type ML Justification
Hour Hour of day (0 to 23) Integer [0, 23] Captures daily diurnal curve (morning commuter surge vs night off-peak).
DayOfWeek Day of the week (0=Monday, 6=Sunday) Integer [0, 6] Distinguishes business-day commercial charging from weekend patterns.
Month Month of the year (1 to 12) Integer [1, 12] Accounts for seasonal climate and HVAC load impact on EV energy transfer.
IsWeekend Weekend indicator flag Binary [0 or 1] High-weight categorical signal for commuter absence.
PrevHour_Demand Immediate lag demand (t-1) in kWh Continuous (kWh ≥ 0) Short-term momentum: current charging session persistence.
PrevDay_Demand Previous-day same-hour demand (t-24) in kWh Continuous (kWh ≥ 0) Strongest predictive feature (57.3% gain): daily cyclical rhythm.
Target_NextHour_Demand Target variable (t+1 demand in kWh) Continuous (kWh ≥ 0) Supervised regression target for XGBRegressor.
