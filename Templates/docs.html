Core Dataset Columns & Operational Purpose

As defined in the project specification (Slide 5)

Column Name Data Type Functional Role in CHARGEUP Handling & Transformation Rule
Station Name String Station identifier & segmentation unit Group key for station statistics & K-Means clustering.
Start Date Datetime Session start timestamp Converted via pd.to_datetime(format='mixed'), floored to hour for demand aggregation.
End Date Datetime Session end timestamp Used to compute session duration and check timestamp validity.
Energy (kWh) Float Electricity transferred to EV battery Filtered to positive values (> 0); summed hourly for XGBoost demand forecasting target.
Ended By String Operational termination indicator Rule-mapped into proxy fault flags: FAULT=0 (Normal), FAULT=1 (Abnormal), or Unknown.
Total Duration Time (hh:mm:ss) Total parked time at charging stall Used for dwell time analysis and station occupancy validation.
Charging Time Time (hh:mm:ss) Active current flow time Measures active power delivery vs idle parking dwell time.
City, Postal Code String Geographic location Identifies Palo Alto, CA municipal and commercial zones.

Dataset Placement & Download Instructions

To refresh or retrain the pipeline with an updated ChargePoint release:

  1. Download the official ChargePoint Data CY20Q4 CSV export from the open data portal (City of Palo Alto Open Data / Kaggle / ChargePoint archive).
  2. Place the CSV file directly into the Data/ directory named as ChargePointData.csv: 
    ChargeUp_EV/Data/ChargePointData.csv
  3. Run the automated feature engineering and model training pipeline: 
    python ml_engine.py
  4. The system will automatically regenerate models (xgboost_demand_model.pkl, kmeans_station_model.pkl), summary statistics (pipeline_summary.json), and dashboard charts.
